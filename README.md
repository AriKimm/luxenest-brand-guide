# luxenest-brand-guide
A brand guide and creative design project created as a capstone project for General Assembly's Creative Skills Academy for Creatives.
## Project
LuxeNest is a boutique interior design and curated home-goods brand focused on modern luxury interiors, personalized design services, and sustainable sophistication.

The project includes a visual brand guide and supporting creative assets developed using Adobe Express and Adobe Firefly.
